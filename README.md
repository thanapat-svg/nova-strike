# Nova Strike

เกมยิงยานอวกาศแนวตั้ง (HTML5 Canvas) เล่นบนเบราว์เซอร์ หรือติดตั้งเป็นแอป Android

## เล่น
- เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ หรือเปิด GitHub Pages ของ repo นี้
- ไฟล์ APK อยู่ในหน้า Releases

## โครงสร้าง
- `index.html` — โค้ดเกมทั้งหมด (ไฟล์เดียว)
- `assets/` — รูปดาว (p*.webp), เนบิวลา (n*.webp), พื้นผิวดาว (s*.webp), เพลง (music/*.mp3)
